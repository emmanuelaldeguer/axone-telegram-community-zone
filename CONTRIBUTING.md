# Contributing

This is currently an experimental learning project.

## Development

```bash
npm install
npm run ci
```

Keep changes small and milestone-focused. New behaviour should include tests where practical. Do not commit `.env`, wallet secrets, Telegram bot tokens or personal identifiers.

## Commit style

Use concise conventional-style commit messages where useful, for example:

```text
feat: add active staking qualification prototype
fix: handle staking pagination key correctly
docs: clarify Telegram enforcement boundary
```
